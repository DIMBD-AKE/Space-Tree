# Space Tree Implementation Plan

**Goal:** 가벼운 macOS 트리맵 용량 앱과 재현 가능한 성능 검증을 완성한다.
**Architecture:** POSIX 메타데이터 스캔 → 불변 파일 트리 → SwiftUI 탐색 및 AppKit 트리맵/가상 목록. FSEvents는 같은 스캔 큐의 증분 갱신을 요청한다.
**Tech Stack:** Swift 5.9+, macOS 13+, 시스템 프레임워크만 사용.
**Spec:** [design.md](design.md)

## Global Constraints
- 외부 의존성 없음. 파일 내용 읽기 및 삭제 없음.
- 파일 I/O는 백그라운드에서 실행. 선택 루트 밖의 심볼릭 링크는 탐색하지 않음.
- 논리 크기와 할당 크기를 구분. 권한 오류와 취소를 처리.

## Review Focus
- 스캔 중 변경과 루트 전환: 이벤트를 보존하며 이전 결과는 버린다.
- 삭제·이름 변경·권한 부족: 오래된 자식과 합계를 남기지 않는다.
- 폴더 이름의 공통 접두사: 경로 구성 요소 기준으로 비교한다.
- 빈 파일·희소 파일·심볼릭 링크: 무한 순회와 잘못된 크기를 방지한다.
- 대량 형제 파일: 화면 렌더링 수를 제한하되 전체 목록에 접근한다.

## Tasks
- [x] `FileTree.swift`: `FileNode`, `ScanToken`, `FileScanner.scan`, `FileScanner.refresh`, `ChangeBatch`. `swift test`로 합계·링크·취소·증분 검증.
- [x] `FolderWatcher.swift`, `BrowserModel.swift`: FSEvents 감시 및 단일 큐·취소·탐색. 실제 생성/수정/이동/삭제 이벤트 검증.
- [x] `Treemap.swift`, `NativeViews.swift`, `SpaceTreeApp.swift`: 캐시된 레이아웃·네이티브 목록·탐색 UI. 면적 테스트 및 실제 앱 UI 확인.
- [x] `Benchmark.swift`, `scripts/build-app.sh`: 릴리스 앱 패키징 및 CLI 벤치마크. 50k/100k 파일, 실제 트리, 증분 처리, 추적 중 CPU 측정 후 `docs/performance.md` 기록.

최종 독립 리뷰의 갱신 실패 경로 보존 및 조상 심볼릭 링크 문제를 재현하고 수정했다. 오래된 목록 선택도 방지했다. 7개 테스트, 실제 UI 확인, 릴리스 빌드 및 서명 검증을 완료했다. 측정 조건과 한계는 [performance.md](performance.md)에 기록했다.

## 초기 분석·권한·저장 공간 개선

- [x] 제한된 병렬 스캔과 부분 결과 탐색. 직렬/병렬 합계·취소 테스트, 같은 10만 파일 트리 5회 비교 및 실제 홈 폴더 단일 분석 비교.
- [x] 안정적인 인증서 서명과 한 번의 권한 안내. 사용자가 전체 디스크 접근을 허용한 뒤 재실행 시 안내 생략 및 실제 휴지통 접근 확인.
- [x] 하단 중복 정보 삭제, Finder 버튼 위치 변경, 디스크 전체 사용량 표시. Data 볼륨 감시 경로 별칭을 실패 재현 후 수정.
- [x] 11개 테스트 통과, 최신 릴리스 빌드·서명 검증 및 실제 UI 확인. APFS 볼륨·스냅샷·권한 오류·Colima 삭제 상태 조사와 측정용 임시 파일 정리.

## 디스크 전체 탐색 추가 개선

- [x] 실제 전체 디스크 프로파일로 두 단계 작업 분배의 편중과 중간 결과 전달 중단 확인. 유휴 작업자에게 깊은 폴더 분배, 열린 폴더의 부분 스냅샷 전달 및 전체 새로 고침의 부분 결과 활성화.
- [x] 트리 합산의 불필요한 Foundation 파일 정보 조회 제거. 전체 분석과 증분 추적의 우선순위 분리, 미완료 용량 표시, 보호된 폴더가 다른 갱신을 막는 오류 수정.
- [x] 고정된 깊은 10만 파일 트리 5회 및 실제 Data 볼륨 비교, 실제 GUI 갱신·최종 집계 확인. 테스트 14개와 서명 검증 통과. 측정용 임시 트리 정리 및 성능 보고서 갱신.
