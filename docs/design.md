# Space Tree

목적: macOS에서 큰 파일과 폴더를 빠르게 찾아 단계별로 탐색하고 실제 파일 변경을 자동 추적한다.

- macOS 13 이상, Swift / SwiftUI / AppKit / CoreServices. 외부 의존성 없음.
- 선택한 루트를 재귀 스캔한다. 내용은 읽지 않고 메타데이터만 조회한다. 숨김 파일과 앱 패키지도 포함하고 심볼릭 링크는 따라가지 않는다.
- 논리 크기를 기본 면적 기준으로 사용하고 할당 크기 전환을 제공한다. APFS 공유 블록·스냅샷 때문에 할당 크기를 실제 회수 가능 공간으로 표현하지 않는다.
- 용량순 트리맵에서 폴더를 클릭하면 진입한다. 경로 버튼·상위 폴더·키보드 이동·Finder 표시를 제공한다. 빈 파일과 작은 항목도 가상화 목록에서 접근할 수 있다.
- 전체 스캔 및 하위 트리 재스캔은 하나의 백그라운드 큐에서 조율하고 최대 4개 작업자로 메타데이터를 읽는다. 유휴 작업자가 생기면 탐색 중 발견한 깊은 하위 폴더를 분배한다. 전체 분석은 userInitiated, 자동 증분 추적은 utility 우선순위를 사용한다. 취소와 오래된 결과 폐기를 지원하며 진행 중인 폴더의 부분 스냅샷도 약 0.5초 간격을 목표로 UI로 전달한다.
- 전체 디스크 접근을 처음 한 번 안내하고 실제 휴지통 접근으로 확인한다. 안정적인 인증서 서명으로 재빌드 시 권한 식별자를 유지한다.
- Finder 버튼은 경로 오른쪽에 하나만 두고 하단 중복 정보를 제거한다. 선택 폴더 합계와 OS가 보고한 디스크 전체 사용량을 구분한다. Data 볼륨의 FSEvents 경로 별칭을 정규화하고 다른 마운트 볼륨은 별도 분석한다.
- 스캔 전에 FSEvents 감시를 시작한다. 이벤트를 합치고 가장 작은 변경 하위 트리를 재스캔한다. 유실 이벤트는 전체 재스캔하며 루트 이동·삭제는 명확한 상태로 알린다.
- 매우 많은 항목은 트리맵의 작은 항목을 묶어 그리되 전체 목록은 유지한다. 매 프레임 파일 접근·레이아웃 계산을 하지 않는다.
- 스캐너 정확성, 변경 경로 축약, 취소, 트리맵 면적을 하나의 테스트 파일로 검증한다. 생성 fixture와 실제 트리로 스캔·증분 갱신·레이아웃·메모리·유휴 CPU를 벤치마크한다.

범위: 읽기 전용 로컬 도구. 삭제, 클라우드 다운로드, 데이터베이스, 백그라운드 상주 서비스는 필요하지 않다.
